# Uso do GitHub Copilot

## Como foi utilizado

O GitHub Copilot foi utilizado como assistente durante a organizacao dos
requisitos, implementacao da interface Tkinter, logica das operacoes, tratamento
de erros, testes e documentacao. As sugestoes foram revistas e os testes
automatizados foram executados para validar os calculos.

## Exemplos de prompts

- "Crie uma calculadora Tkinter em tons de azul com botoes arredondados e
  historico de calculos."
- "Implemente as operacoes basicas usando Decimal e trate entradas invalidas e
  divisao por zero."
- "Crie testes unitarios para calculos decimais, operandos negativos e erros."
- "Revise a interface e a documentacao sem alterar arquivos fora do escopo."

## Boas praticas

- Revise o codigo sugerido antes de aceita-lo.
- Execute os testes depois de alterar as regras de calculo.
- Nao envie credenciais, tokens ou dados privados nos prompts.
- Mantenha os commits focados em mudancas reais e relacionadas.
